# Divyansh Garg — Problem to Product Portfolio (Make-A-Ton Aesthetic Edition)

An exact preservation of the original portfolio content, redesigned with the iconic **[Make-A-Ton](https://www.makeaton.in/)** comic book / neo-brutalist / pop-art aesthetic!

Built with **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## 🎨 Make-A-Ton Design System Features

- **Typography**:
  - `Bangers`: Big, bold comic display headlines with heavy text stroke (`-webkit-text-stroke`) and 3D text shadow.
  - `Titan One`: Punchy rounded comic headline & button font.
  - `Space Mono`: Monospace tags, metadata, and timestamps.
  - `Space Grotesk`: Clear modern readable body copy.
- **Graphic Elements & Stylings**:
  - Thick neo-brutalist black borders (`border-3 border-[#0C0E0F]`).
  - Solid hard drop shadows (`box-shadow: 6px 6px 0 #0C0E0F` / `8px 8px 0 #0C0E0F`).
  - Tactile comic buttons with active push-down interaction.
  - **Tilted Tape Banners (`TapeBanner`)**: Infinite animated marquee strips tilted across sections (`✦ PROBLEM TO PRODUCT ✦`).
  - **Make-A-Ton Timeline Chapter Style**: Dedicated chapter card format (`Chapter 01`) with timeline dates, company leads, and comic boxes.
  - Halftone dot patterns, comic dialogue tags, and the cheering red mascot.
  - Floating **"🚨 DO NOT CLICK"** Easter Egg button with interactive Chai Clicker, Recruiter Speedrun, and Instant Offer Letter generator.
